# internet-speed-test

Консольный скрипт на Node.js для замера скорости скачивания. Скрипт делает **10 последовательных запросов** к указанному адресу и дожидается полного ответа на каждый. Затем выводит **среднее время запроса**, **общий объём скачанных данных** и **скорость скачивания**.

Внешних зависимостей нет: используются встроенные `fetch`, `performance` и `node:test`.

## Требования

- Node.js **22 или новее** (проверено на 24.21.0)

## Запуск

```bash
git clone https://github.com/Shaxriyor0428/internet-speed-test.git
cd internet-speed-test

node src/cli.js <url>
```

`npm install` не нужен. Другие способы запуска:

```bash
npm start -- <url>
npx . <url>
```

Примеры:

```bash
# Тяжёлая картинка (~1.8 МБ)
node src/cli.js "https://images.unsplash.com/photo-1506744038136-46273834b3fb?fm=jpg&q=90&w=4000"

# Тестовый файл Cloudflare заданного размера (здесь 10 МБ)
node src/cli.js "https://speed.cloudflare.com/__down?bytes=10000000"
```

> Берите URL в кавычки. Без них bash обрежет ссылку на символе `&`, и скрипт замерит другой адрес, а PowerShell вообще не запустит команду.

Справка: `node src/cli.js --help`

## Единицы измерения

Все единицы **десятичные (СИ)**, без двоичных 1024.

| Величина | Единица | Пояснение |
|---|---|---|
| Скорость (основная) | **Мбит/с**, мегабиты в секунду | 1 Мбит = 1 000 000 бит |
| Скорость (дополнительно) | **МБ/с**, мегабайты в секунду | 1 МБ/с = 8 Мбит/с |
| Объём | байты; для краткости Б / КБ / МБ / ГБ | 1 КБ = 1 000 байт, 1 МБ = 1 000 000 байт. Точное число байт выводится в скобках |
| Время | мс до 1 секунды, дальше с | 1 с = 1 000 мс |

**Почему Мбит/с.** В мегабитах в секунду скорость указывают провайдеры в тарифах и сервисы вроде Speedtest. Поэтому результат можно сразу сравнить с тарифом. МБ/с выводится рядом, чтобы было понятно, сколько мегабайт файла скачивается за секунду.

## Как считается

- **Время запроса** — от вызова `fetch` до получения **последнего байта** тела ответа. Сюда входят DNS, установка TCP/TLS-соединения, ожидание ответа сервера и само скачивание.
- **Объём** — реальное число байт тела ответа. Оно считается по мере чтения потока, заголовку `Content-Length` скрипт не доверяет. HTTP-заголовки в объём не входят.
- **Среднее время запроса** = сумма времён всех запросов / 10.
- **Скорость** = (общий объём в байтах × 8) / (суммарное время в секундах) / 1 000 000 → Мбит/с.

Скорость считается по суммарным значениям, а не как среднее арифметическое скоростей отдельных запросов. В этом случае каждый байт имеет одинаковый вес, а результат равен объёму, реально скачанному за реально потраченное время. Если просто усреднить скорости, быстрые запросы завысят результат.

## Особенности поведения

- **Запросы строго последовательные.** Следующий запрос начинается только после того, как предыдущий ответ скачан полностью.
- **Без сжатия.** Скрипт отправляет `Accept-Encoding: identity`, чтобы сервер не сжимал ответ. Иначе `fetch` распакует gzip на лету и посчитает распакованный объём вместо реально переданного.
- **Первый запрос обычно медленнее.** На нём устанавливается соединение, а следующие запросы используют его повторно (keep-alive).
- **Ошибка останавливает замер.** Если сервер ответил не `2xx` или запрос упал (нет сети, неверный домен, обрыв соединения), скрипт выводит номер запроса и причину и завершается с кодом `1`. Статистика по неполному набору запросов была бы некорректной.
- **Скорость ограничена и сервером.** Для честного замера выбирайте большой файл (от нескольких МБ) на быстром CDN. На маленьком файле основное время уходит на установку соединения, а не на скачивание.

## Тесты

```bash
npm test
```

Тесты используют встроенный `node:test` и не ходят в интернет: для проверки `measureRequest` в них поднимается локальный HTTP-сервер. Проверяется:

- формулы: среднее время, общий объём, скорость (в том числе что скорость = общий объём / общее время);
- форматирование единиц;
- разбор и валидация аргументов: нет URL, лишние аргументы, URL без схемы, не-HTTP схемы;
- подсчёт байт с `Content-Length` и без него (chunked);
- скрипт дожидается всего тела ответа, а не только заголовков;
- отправку `Accept-Encoding: identity`;
- ошибку при ответе не `2xx`.
